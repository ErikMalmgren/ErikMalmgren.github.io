I'm a software engineer at Netcompany, working across the stack on client web applications, Java and Spring on the backend, React on the front. The backend is where most of my work happens and where I want to keep going.

A lot of it is integration work. I've built secure workflows against Danish public infrastructure, notably NemKonto, that distribute digital and physical correspondence and sensitive information to private citizens, plus the backend frameworks and batch jobs behind large-scale communication processes, all of it under compliance constraints for handling personal data.

Before that, five years at LTH. My thesis was an interview study on generative AI in pair programming and code review; the interesting result was that the benefit splits by seniority. Seniors gain because they spot errors in generated code immediately, juniors gain a better path to self-directed learning, but only when the tool is used deliberately.
